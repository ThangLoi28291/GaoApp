InterVariable.woff2 is the unmodified official Inter v4.1 font, pinned to upstream
commit e3a3d4c57d5ecc01453a575621882a384c1995a3. See SOURCE.txt for URL/SHA256
and OFL.txt for the exact accompanying license. The two unproven reference subsets
have been removed from the published asset tree, with immutable before hashes.
No remote font/CDN request is made. Inter includes Vietnamese/Latin glyphs and is
followed by Segoe UI/Arial fallbacks; font-display:swap keeps text visible.
This packaging does not enable public launch or alter the preview host guard.
