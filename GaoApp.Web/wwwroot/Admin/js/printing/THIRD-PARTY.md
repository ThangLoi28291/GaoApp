# QZ Tray JavaScript connector

Unmodified qz-tray.js, version 2.2.6, licensed LGPL-2.1-only.
Source: https://github.com/qzind/tray/blob/v2.2.6/js/qz-tray.js
SHA-256: B0A0AFDE74511E5284195CC875BC862B1EA4233F6C6AECB3AD485430A56BF4A6
License text: qz-tray.LICENSE.txt. The readable JavaScript source is shipped alongside the application and can be replaced independently.

This is the browser connector only; the QZ Tray client application and signing certificates are not bundled. No private signing key is distributed to browsers. Unsigned connections/print jobs use QZ Tray's user approval dialogs. Silent printing requires separately provisioned trusted message signing, including an offline-capable design if required.
